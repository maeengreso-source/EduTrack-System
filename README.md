# EduTrack System

A Student Information System developed using Node.js, Express.js, EJS, and MySQL.

## Features

- User Authentication
- Student Management
- Attendance Management
- Dashboard
- Reports

## Technologies Used

- Node.js
- Express.js
- EJS
- Bootstrap 5
- MySQL

## Installation

```bash
git clone https://github.com/maeengreso-source/EduTrack-System.git
cd EduTrack-System
npm install
npm start
```
